# 数值组件回归夹具

这里保留 V1 的 `analysis.json` 与 `demo-data.json`，用于兼容性、离线组件及数值回归测试。状态采用 schema 1.0；新论文阅读使用 schema 1.1 的研究概览、原文结构导览与重点问题选择。

`demo-data.json` 中的 77 个测光点均为固定种子的模拟数据，另有均匀源单透镜查表与静态二元透镜焦散图集。它们用于解释机制，不是 OGLE 的真实测光或论文重新拟合结果。生成方法见 `scripts/build_data.py`。

报告可按仓库 README 中的命令在本地生成。该目录不包含论文 PDF、提取全文或原论文图片。
