# 四种阅读模式：默认按原文章序

`analysis.json` 存储关键科学证据与原文映射，`report.md`（按需 `report.html`）供读者阅读，`analysis-notes.md` 保存覆盖、执行和溯源。脚本不会独立阅读原文，也不会自动评判物理推理是否正确。

|模式|用途|默认组织|
|---|---|---|
|`quick`|初步判断论文的研究对象、贡献和结果|如实说明只读摘要/部分内容，不伪称覆盖未读的所有章节|
|`deep-md`|充分理解研究问题、推导、测量及其结论|概览→简短的原文论证路线→按作者主要章序精讲→独立评价→后置详细原文索引|
|`interactive-html`|深入阅读并在适宜时探索物理反事实|同 deep 的论证顺序；优先关键原图，交互可为零|
|`critical-review`|了解作者证据并评价结论强度|先按原文完成科学论证重建，再集中审查模型、标定、统计、系统误差与替代解释|

新任务默认 schema 1.3：`reader.organization="paper-order"`，`reader.argument_route` 为开篇的作者论证路线，`reader.roadmap` 为文后真实 §/页码索引，`sections[].source_sections` 关联原文章节。`reader.throughline/connections` 可选，不为普通报告重复填写内部计划。确需专题重组，写明 `restructured` 和具体 `departure_reason`，并保持主要章节覆盖。旧 schema 1.0/1.1 可继续构建，不自动改写其正文与记录。

重要的观测推断、模型条件与物理限制可占篇幅；有用的数学推导放在首次需要的章节。作者论文没有相应部分时，不能为了统一结构而制造理论定理、消融、模拟对照或仪器误差预算。独立评价不得压过论文的正面解释，限定语只在会改变眼前结论时出现一次。

普通交付一次写作、一次简短核验与构建即结束，不做额外读者测试、复杂的发布验收或训练/数值复现。只有明确需求才扩展检查。
