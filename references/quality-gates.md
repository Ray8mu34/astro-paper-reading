# 轻量质量检查：原文章序、科学解释、交付文件

普通论文精读仅做**一次合并式交付检查**，不写另一份验收报告。核查在实际阅读、推导和解读图表时已自然完成的工作，不开展第二轮项目式测试。

1. **原文结构**：`reader.roadmap` 是否按真正 PDF 的主要章节登记；`sections[].source_sections` 是否覆盖相应章节并维持原顺序；作者如何提出问题、选择测量/模型/理论方法、展示主要证据和讨论结论，是否得到合理篇幅。程序只能验证已记录的章号，不能发现写作者漏登记的真实章。
2. **科学与物理关系**：关键公式、单位、参考系、时间系统、图轴、观测/模型身份、统计定义、重要数值与原文是否一致。对核心主张，检查直接测量、模型依赖与先验推断是否被正确区分；重要简并/选择效应/近似范围是否在影响结果的位置说明一次。没有必要核对每个普通名词或计算所有作者未要求的数值。
3. **阅读体验**：科学动机是否先于难公式，原文章节之间衔接是否清晰，关键原图/证据是否就地讲解，独立评价有没有抢在作者论证之前；删除重复免责声明与工作日志。构建与一致性校验各运行一次，真实问题局部修复即可。

```sh
python scripts/validate_skill.py --analysis WORK/analysis.json --require-artifacts
```

只需 Markdown 则使用 `--md-only`。校验输出通过只能说明格式、映射和产物一致，不能替代物理正确性或首次读者的理解。**不强制**前四分之一测试、逐章无提示复述、独立读者模拟、人工验收记录、多轮评分、`reader-review.json`、pytest、浏览器/响应式专项测试、MCMC/数据再拟合、数值组件全量回归。这些只有用户明确要求或本次修改了相应代码/数值组件时才按需做。不要为未执行的可选工作制造待办矩阵。
