# 增加领域，不复制整套提示词

新领域模块采用与 microlensing 相同的入口：使用范围、约定卡、关键可观测量、从可观测到物理参数的映射、近似/简并、主要系统误差、可靠数值方法、基准算例和第一手文献。将其加入主 SKILL 的按需加载表即可；新增领域也继承原文章节顺序与论证还原原则，不修改证据分类或构建系统。

恒星物理首先注意大气/演化模型、金属丰度与年龄简并、消光、非局域热平衡、混合长与旋转假设。星系研究注意红移、静止系波长、光度/质量转换、初始质量函数与样本完备性。宇宙学区分背景模型、距离类型、h 的幂、宇宙方差和选择函数。系外行星注意几何选择、恒星活动、投影量与真实量、星参数传播。流体力学注意方程闭合、守恒、激波捕获、边界和分辨率。

这些是路由提示，不是假装已建立和验证上述全部领域求解器。每次在一个新领域输出定量图时，必须取得该领域的第一手定义、实现和验证。优先选择少而可靠的参考模块；没有来源时不把物理名词扩展成百科清单。

**只有在开发新领域模块或新计算组件时**，才考虑标准基准、真实论文案例、领域误判陷阱与旧案例回归。普通新领域论文阅读不触发这些开发验收；新组件仍记录必要的 schema/version/basis/units/frame/domains/solver/validation 并遵循统一 Figure Kit。
